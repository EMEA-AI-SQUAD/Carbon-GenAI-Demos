# IBM Power — Carbon GenAI: On-Prem Granite AI for Regulated Clients

An IBM Power platform reality demo for regulated-industry pre-sales where a client's own IBM Power10 hardware runs IBM Granite 4.0 Micro via llama.cpp — no cloud API, no watsonx.ai SaaS, no data leaving the building — and Bob deploys the full stack from a fresh TechZone reservation in under 25 minutes. Bob generates a running Carbon Design System web application with 9 live use cases (entity extraction, multilingual IT Ops, logistics data extraction, PII/GDPR redaction, passport KYC, document risk discovery, campaign brief building, RFP assistance, and talent acquisition), a 15-step automated deployment script validated on ppc64le RHEL 9.4, a pre-sales demo script with concrete sample inputs for each use case, and a deployment skill that guides Bob through SSH connection, service verification, and all known failure modes.
